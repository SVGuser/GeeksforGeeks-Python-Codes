# `posInfinite` — Finding the $k$-th Character in an Infinite Recursive String

## Overview
The `posInfinite` method finds the $1$-indexed character at position `pos` in a sequence of strings generated by iteratively appending a growing block of `$` characters followed by the **reversed** version of the previous string.

---

## Recurrence Pattern

Starting with an initial string $S_0 = s$ of length $L_0 = |s|$, each step $k \ge 1$ constructs the next string $S_k$ as:

$$S_k = S_{k-1} + \underbrace{\$\$\dots\$}_{k \text{ times}} + \text{reverse}(S_{k-1})$$

Consequently, the length $L_k$ at step $k$ satisfies:

$$L_k = 2 \cdot L_{k-1} + k$$

---

## Implementation

```python
class Solution:
    def posInfinite(self, s: str, pos: int) -> str:
        length = len(s)
        step = 1
        while length < pos:
            length = 2 * length + step
            step += 1
        while step > 1:
            step -= 1
            previous_length = (length - step) // 2
            if previous_length < pos <= previous_length + step:
                return '$'
            elif pos > previous_length + step:
                pos = length - pos + 1
            length = previous_length
        return s[pos - 1]
```

---

## Step-by-Step Breakdown

1. **Forward Expansion (`while length < pos`):**
   - Repeatedly doubles `length` and adds `step` until `length >= pos`.
   - Identifies the minimum expansion level needed to cover `pos`.

2. **Backward Reduction (`while step > 1`):**
   - Decrements `step` and recovers the prior string length using:
     $$\text{previous\_length} = \frac{\text{length} - \text{step}}{2}$$
   - Determines which of the three segments `pos` falls into:
     - **Left Segment ($1 \le \text{pos} \le \text{previous\_length}$):** Lies inside $S_{k-1}$; `pos` remains unchanged.
     - **Middle Segment ($\text{previous\_length} < \text{pos} \le \text{previous\_length} + \text{step}$):** Lies in the separator block of `$` characters; immediately returns `'$'`.
     - **Right Segment ($\text{pos} > \text{previous\_length} + \text{step}$):** Lies inside $\text{reverse}(S_{k-1})$; maps `pos` back to its mirrored index in $S_{k-1}$ via:
       $$\text{pos} \leftarrow \text{length} - \text{pos} + 1$$

3. **Base Case Lookup:**
   - Once reduced back to the original string $S_0$, returns `s[pos - 1]` (converting from $1$-based to $0$-based indexing).

---

## Example Walkthrough

Suppose `s = "abc"` ($L_0 = 3$) and `pos = 10`:

| Phase | `step` | `length` | `previous_length` | Action / `pos` Update |
| :--- | :---: | :---: | :---: | :--- |
| Init | $1$ | $3$ | — | $3 < 10$, expand |
| Expand 1 | $2$ | $2(3) + 1 = 7$ | — | $7 < 10$, expand ($S_1 = \text{"abc\$cba"}$) |
| Expand 2 | $3$ | $2(7) + 2 = 16$ | — | $16 \ge 10$, stop ($S_2 = \text{"abc\$cba\$\$abc\$cba"}$) |
| Reduce 1 | $2$ | $16$ | $(16 - 2) / 2 = 7$ | $10 > 7 + 2 \implies \text{pos} = 16 - 10 + 1 = 7$ |
| Reduce 2 | $1$ | $7$ | $(7 - 1) / 2 = 3$ | $7 > 3 + 1 \implies \text{pos} = 7 - 7 + 1 = 1$ |
| Base Case | $1$ | $3$ | — | Return `s[1 - 1]` $\rightarrow$ `'a'` |

---

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}\left(\log\left(\frac{\text{pos}}{|s|}\right)\right)$ — `length` more than doubles on every expansion step, so both loops execute at most $\mathcal{O}(\log(\text{pos} / |s|))$ iterations.
- **Space Complexity:** $\mathcal{O}(1)$ — Only scalar integer variables are used; no expanded strings are constructed in memory.
